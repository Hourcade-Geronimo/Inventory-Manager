# Inventory Manager

A simple inventory management system built with **C# and .NET**, focused on practicing clean architecture principles,
domain modeling, separation of concerns, and repository/service patterns.

## Current State

The project currently includes:

- Product management
- Category management
- Supplier management
- Stock movement tracking with history of stock entries and exits.
- Product relationships with categories and suppliers
- Domain validation and custom exceptions
- Generic repository pattern
- In-memory repositories for testing only
- SQLite db implemented for executable
- Application services for each entity
- Console-based interface
